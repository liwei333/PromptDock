## 0. 需求冻结：本轮只做什么

**一句话产品定义：** 一个安装在自己 Mac 上、无需登录和网络的提示词工作台。能收藏、分类、搜索、编辑常用 AI 提示词，**鼠标点击「复制」立即复制全部文本到 macOS 系统剪贴板**，也可使用全局快捷键调出快速搜索面板。

- **唯一存储来源：本机 SQLite**，安装在用户应用数据目录；关闭/重启/断网后数据仍在。禁止用浏览器 `localStorage` 作为正式数据源。
- **100% 离线业务逻辑**：不需要账号、云同步、远程 API、外部数据库、订阅、登录、支付、AI 模型接口、遥测/埋点。
- **单人单机**：优先适配本人 MacBook（Apple Silicon）；无需 iPhone/iPad 客户端、iCloud、Windows/Linux 首发支持。
- **复制≠自动粘贴**：点击复制只把文本放进系统剪贴板。用户回到 ChatGPT、Codex、Kimi、Claude 等目标窗口自行 `⌘V`。V1 不模拟按键、不控制其他应用、不请求「辅助功能」或「屏幕录制」权限。
- **视觉基准冻结**：已确认的 `UI_PROTOTYPE.html` 仅作色彩和轻量 macOS 视觉语言参考；当前工作台复用深色 76px 图标栏、蓝紫色主操作、浅底色工作区和白色面板，布局与控件以本 PRD 和 `UI_DESIGN_SPEC.md` 为准。
- **UI 演示数据说明**：HTML 文件是独立浏览器原型，示例数据暂存在 `localStorage`；**正式 macOS App 首次启动默认只有分类、没有示例提示词**。演示样例可选通过 JSON 导入。

## 1. 背景与问题

使用 AI 执行研究、编程、产品需求和写作任务时，会积累长度不同的角色提示词、工作流程提示词。当前散落在文档/聊天记录里，使用时需要查找、选择、复制，耗费时间。真正需要的是一个可常驻、可搜索、一键复制的**个人提示词工具箱**，而非联网的提示词商城或 AI 聊天软件。

### 产品目标

1. 普通提示词在主窗口「**一次点击**」即可成功复制到系统剪贴板，**不需要先选择正文**。
2. 在别的应用工作时，快捷键呼出快速面板，输入搜索词，按回车复制第一结果。
3. 本机独立保存和管理提示词，支持分类/收藏/置顶；无网络时功能完全可用。
4. 能以 JSON 文件导出备份、在数据丢失或换电脑时手动恢复；导入不静默覆盖。
5. 提示词里出现 `{{项目名称}}` 等变量时，先填写变量，复制**替换完成后的全文**。

### 非目标（硬排除）

- 账号系统、云端存储、iCloud/CloudKit、设备同步、P2P 同步、局域网 API。
- AI 自动生成/改写提示词、联网搜索、模型调用、API Key、调用统计/计费。
- 浏览器扩展、对其他软件的自动粘贴、键盘注入、屏幕识别、OCR。
- 企业团队协作、权限管理、版本历史、在线市场、支付。
- Windows 首发支持（未来可评估，但本轮不做适配测试）。

## 2. 目标用户与场景

- **用户**：经常在 Mac 上使用 AI 的个人开发者/研究员；只有一个本地工作空间。
- **场景 A — 每日重复任务**：打开 PromptDock，在主工作台列表中选择常用提示词并点击「复制」，再切回 AI 窗口粘贴。
- **场景 B — 不离开当前工作流**：在编辑器/浏览器里按 `Option + Space` 唤起 PromptDock 快速面板，输入「代码审查」，回车复制，面板自动隐藏。
- **场景 C — 整理提示词**：新建、修改标题和正文、指定分类、添加标签、标记收藏/置顶，重启应用后数据无变化。
- **场景 D — 模板使用**：编辑正文含 `{{项目名称}}`/`{{目标用户}}`；复制时展开变量输入；全部填写后，预览和剪贴板内容一致。
- **场景 E — 备份**：导出 JSON 保存到自己选择的目录，随后在空库中导入，数量、正文、分类、置顶/收藏状态正确。

## 4. 功能详细规则

### FR-01 本地持久化

- 应用启动解析 Tauri `app_data_dir`，创建 `promptdock.sqlite3`，由 Rust `sqlx` 执行迁移。不要把数据库放在代码仓库、应用安装包或 iCloud Drive 内。
- 唯一真实数据读写路径：Vue → typed `invoke` → Rust commands → Repository → SQLite；Pinia 仅维护界面状态，不是持久化事实来源。
- 首次启动创建 6 个默认分类：「技术研发」「投资研究」「产品规划」「内容创作」「商业运营」「通用效率」，**不自动写入示例提示词**。
- 所有写操作成功后再展示「已保存」；失败保留编辑内容、允许重试。
- 全局单实例运行；关闭快速面板不会关闭主应用；退出应用再次打开仍能查看数据。

### FR-02 提示词字段与限制

| 字段 | 规则 |
|---|---|
| 标题 | 必填，去首尾空格，1–80 字符；允许重名 |
| 正文 | 必填，保留正文换行/空格，1–100,000 字符；禁止静默截断 |
| 说明 | 可选，最多 160 字符 |
| 分类 | 必选，默认「通用效率」；只允许指向真实分类 |
| 标签 | 可选，最多 10 个；单个最多 30 字符；去重、去首尾空格 |
| 收藏 | 布尔值，与置顶相互独立 |
| 置顶 | 布尔值，表示是否加入便签五槽位；手工顺序由 `pin_order` 决定 |
| 使用次数 | 系统计数；只有剪贴板真正写入成功才 +1 |
| 最近使用 | 复制成功时更新；普通保存不更新此字段 |
| 创建/修改时间 | SQLite 保存 UTC 毫秒时间戳，UI 按本地时间展示 |

- 编辑过程中有未保存变更时，关闭窗口/弹层/按 Esc 时弹出「放弃更改？」确认。
- 删除提示词必须确认；成功后列表和计数立即更新；V1 不做回收站，要求用户有导出备份能力。
- 点击提示词列表行会选中该项并更新右侧常驻详情面板；**普通提示词的行内「复制」按钮直接复制，不触发行选择或改变当前详情**。

### FR-03 一键复制

1. 点击「复制」读取该条**原始全文**（保留换行）。
2. 普通提示词调用 macOS 系统剪贴板写入，成功后显示「已复制」，再更新复制次数/最近使用时间；如果使用统计写入失败，要明确显示「复制成功，统计更新失败」。
3. 失败显示错误，不递增计数；不更改旧剪贴板内容；禁止用复制成功的虚假 Toast 掩盖错误。
4. 不发送网络请求，不自动切回浏览器，不模拟 `⌘V`，不覆盖其他应用文本框。
5. 连续点击复制，系统剪贴板只保留**最后一次成功复制**的内容（符合系统行为）。

### FR-04 变量模板

- 变量语法：`{{变量名}}`，两侧允许空格；同名变量只生成一个输入框。
- 变量名允许中文、英文、数字、下划线及空格，剔除首尾空格后长度 1–40 字符；不执行表达式，不解析任意代码。
- 从列表行内按钮或常驻详情面板触发模板复制时，在常驻详情面板中进入变量填写；在快捷面板中触发时，则在快捷面板中填写变量，均不直接复制原始占位符。
- 必填的每一个变量有非空值才可复制，空值有错误提示；填写过程中预览实时替换。
- **参数替换使用回调/字面值，不使用模板引擎执行、`eval` 或动态 JS**；变量内容中的 `$`、反斜杠和 `{{...}}` 视为普通输入文本，不做二次解析。
- 用户填写的变量值在面板关闭后清空，V1 不存入数据库；保存的是原模板正文。
- 一个模板最多 30 个不同变量；超出提示而不静默裁剪。

### FR-05 / 07 / 08 查询与排序

- 搜索标题、说明、正文、标签、分类名称；不区分英文字母大小写；中文采用**子串包含**，不依赖联网或拼音搜索。
- 输入关键词后延迟约 150ms 查询，避免每敲字进行全库扫查。搜索结果为空要展示「没有找到符合条件的提示词」。
- 76px 图标栏提供工作台重置、仅看收藏、分类管理、快捷便签和设置与运行信息入口；它不承载旧式独立筛选入口或分类计数。
- `WorkbenchFilters` 将关键词、分类、标签、仅看收藏、仅看置顶、仅看最近使用和仅看变量模板作为可组合筛选；有条件时提供“清空”，分类选择器也可进入“管理分类…”。
- 默认排序为“最近更新”；另可选“最常使用”和“标题排序”。排序与上述组合筛选分开控制，不将用户文本直接拼成 SQL。
- 快捷面板最多展示前 12 个搜索结果；置顶优先，再按使用次数、最近修改时间排序。

### FR-06 分类、收藏、置顶

- 默认 6 类见上；允许创建自定义分类，名称 1–18 字符，不允许重名（忽略拉丁字母大小写）。
- 新建提示词时选择分类，不创建隐形分类。
- 收藏与置顶独立开关，可以同时开启；置顶上限为 **5 条**，详情见 FR-17，点击状态变更应立即保存并反馈。
- V1.0 分类可「新建/查看/筛选」，「重命名/删除分类」在 P1，不可伪装成已实现。

### FR-09 快捷复制面板

- **主界面局部快捷键 `⌘K`**：打开应用内命令面板。
- **系统级快捷键 `Option + Space`**：在任意桌面应用前台时唤起 PromptDock 的独立轻量窗口，并将焦点置于搜索框。
- 不使用 `⌘Space`（与 Spotlight 常见冲突）；如 `Option + Space` 已被系统/第三方占用，要在设置或提示中展示冲突原因，并提供点击主窗口手动打开的退路；P1 才做任意快捷键配置。
- 快捷面板宽度约 680px，最大高度屏幕 70%，居中靠上。显示搜索框、最多 12 行候选、复制提示和 Esc 关闭。
- 打开时清空上次查询、聚焦搜索框。`↑↓` 切换高亮候选，`Enter` 操作当前项，`Esc` 关闭。
- 普通提示词复制成功后关闭快捷面板；模板转变量填写界面，提交复制后再关闭。
- 与主窗口共用 SQLite，不各自复制一份状态；禁止创建新的独立数据库。
- **全局快捷键的真实生效必须在 macOS 原生 Tauri 环境验收；HTML 页面无法验证其他 App 前台的全局行为。**

### FR-10 备份与恢复

- 导出：系统文件保存对话框，生成 UTF-8 JSON，文件名建议 `PromptDock_backup_YYYY-MM-DD_HH-mm.json`；包含分类、提示词、收藏/置顶/使用统计和导出版本信息；不包含本机设备状态/快捷键或其它隐私记录。
- 导入：选择本地 `.json`，限定大小 ≤ 10 MiB、最多 10,000 条，预校验字段后**显示预览**：待导入数量、重名/ID 冲突数、预计新增分类数、无效记录数。
- 两种明确选项：**合并导入（默认）** / **替换现有库（危险操作，二次确认且先创建安全备份）**。取消后数据库完全不变。
- 合并时：不同 ID 正常新增；相同 ID 且内容相同跳过；相同 ID 但内容不同，新建 UUID、标题加「（导入副本）」避免覆盖。允许同名不同内容。
- 导入必须在一个数据库事务中完成；遇任何校验或写入错误全部回滚；不允许只成功导入部分数据而冒充全部成功。
- 兼容旧版浏览器原型的导出结构 `{app:'PromptDock',version:1,categories:[string],prompts:[{id,title,body,category,description,tags,favorite,pinned,uses,createdAt,updatedAt,lastUsed}]}`，但**不要自动读取浏览器 localStorage**。对非 UUID 的旧格式 ID 使用稳定映射生成 UUID，保证同一旧文件重复导入时能识别冲突，而不是每次无条件新增。
- 备份是明文 JSON，设置页明确提示用户不要在备份中保存密码、私钥等秘密内容。

## 6. 状态、错误与边界

| 情况 | 预期行为 |
|---|---|
| 第一次安装 | 空提示词列表 + 6 类，展示「新建提示词」引导 |
| 无搜索结果 | 空态，支持清除查询 |
| 系统剪贴板写入失败 | 明确失败 Toast，不增加使用计数 |
| 数据库损坏/无写入权限 | 阻止修改并展示错误及数据库位置，不覆盖原文件 |
| 无网络 | 无功能损失，应用不尝试请求远端地址 |
| 启动第二个程序实例 | 聚焦已运行窗口，不同时写同一 DB |
| 导入数据格式错误 | 说明原因，现有库不变 |
| 编辑时按 Esc | 若有未保存修改，询问是否放弃 |
| 快捷键被其他程序占用 | 不崩溃；提示失败并保留点击入口 |
| 提示词较长 | 显示预览截断，但复制绝不能截断 |
| 变量重复出现 | 只输入一次，全文所有对应位置替换 |
| 模板变量未填 | 禁止复制，保持编辑面板和用户输入 |

## 7. 非功能要求

- **数据可靠性**：每次新增/编辑后立即 commit；正常退出和强制结束后已提交数据可恢复；修改已有数据库前先跑 migration/backup 测试。
- **性能目标（MacBook M2，1,000 条提示词，普通长度）**：主列表首次加载目标 < 1s，搜索过滤响应目标 < 300ms，普通提示词点击复制到回调成功目标 < 300ms。属于测试目标，非平台保证值。
- **隐私**：应用无远程地址、第三方统计 SDK、自动更新或同步功能；提示词数据本地明文 SQLite，系统磁盘加密由 FileVault 等机制提供，不宣称数据库级加密。
- **可访问性**：图标按钮 `aria-label`/tooltip、可见焦点样式、键盘可操作、Toast 配合 `aria-live`；颜色对比清晰。
- **分辨率**：目标主窗口 1280×800 及以上，最小可用 1024×700；支持 Mac 13/14 英寸屏幕。
- **兼容性**：开发目标 macOS 13+；具体最低版本依赖项目所选 Tauri/插件兼容性，开发前以安装依赖版本核验。
- **安装**：本人使用，以本机 `tauri build` 产出 `.app` 或本地安装包；不要求 App Store 签名、公证、上架。

## V1.1 新增核心需求：FR-17 快捷便签模式（P0）

**产品意图**：在 Mac 其他软件（浏览器、IDE、AI 客户端）旁边放一个和桌面黄色便签相仿的迷你窗口，只呈现用户指定的五条常用提示词。**点击一行即可复制整段正文到 macOS 系统剪贴板**，不必选择文本、不必打开完整提示词库。

### FR-17.1 窗口与显示

- 便签属于 PromptDock 的第三个 **独立 Tauri 窗口 `sticky`**，不是对主窗口缩放；主窗口 `main` 可隐藏，便签仍可单独使用，快捷搜索窗口 `quick` 仍保持独立。
- 便签只有两档受控密度：默认 **舒适模式 420×695 逻辑像素**，**精简模式 340×270 逻辑像素**。用户可一键双向切换并跨重启保留选择；两档均为精确逻辑尺寸，不提供任意拖拽缩放。
- 便签使用浅黄色主题，保持和用户截图便签相近的视觉意象：细边框、小阴影和轻量原生 macOS 窗口语言。舒适模式的每行可以展示说明或正文摘要、模板/复制动作语境；精简模式以标题为主，隐藏这些扩展信息，五个槽位和完整复制能力不变。
- 标题栏恰有三个操作：密度直接切换、通用「切换到完整模式」、收起便签。密度按钮描述**目标状态**：舒适模式显示 `切换到精简模式`，精简模式显示 `切换到舒适模式`，图标也随目标同步变化。
- 中部始终为 5 个槽位；底部只有「排序」和「始终置顶」。不提供通用底部「管理/管理置顶」按钮，也不提供齿轮或独立便签设置对话框。
- 不足 5 条时显示剩余空位和去主库添加的引导；0 条时仍可以打开窗口，不得显示演示假数据。超长名称单行省略号，行的无障碍名称仍包含完整标题。
- 主窗口入口「便签模式」；Dock/应用菜单提供「打开主窗口」「打开/收起便签」「退出 PromptDock」。`sticky` 关闭等价于 `hide()`，不退出 App。首次安装默认隐藏；之后记住可见状态和位置，必要时可通过菜单恢复。

### FR-17.2 置顶与顺序

- **便签最多容纳 5 条置顶提示词**。首次置顶按加入顺序排到末尾，后续允许在管理界面上移/下移；复制不会改变顺序。
- 当已有 5 条时，用户将第 6 条勾选「加入便签」，保存应被拒绝，明确提示「便签已满，请先移除一条」；原编辑内容不能丢失。也可以额外实现**明确确认后替换某一项**，但不得静默挤掉旧置顶。
- 收藏与便签置顶依旧完全独立。取消置顶只改变 `is_pinned/pin_order`，不删除提示词、不取消收藏。
- 便签底部「排序」不是通用导航：点击后进入主窗口并携带排序意图，直接打开既有的「管理置顶」`StickyManagerDialog`。如果主窗口已有编辑、导入选择/预览或其他模态操作，该意图进入安全队列，在现有操作关闭后打开，不得丢弃或强行覆盖当前工作。
- 数据库使用 `prompts.is_pinned` + 新增 `prompts.pin_order (1..5 or NULL)` 存储顺序。数据库更新必须在单事务内校验至多五条且槽位不重复；应用内多窗口并发也不许写出冲突。

### FR-17.3 复制、模板、焦点与反馈

- **普通提示词**：鼠标单击任意行或聚焦后按 Enter/Space → 复制完整原文（不含省略号）到系统剪贴板 → 显示短暂「已复制」反馈；便签**不自动关闭**。
- 所有入口复用主程序的 `copyPrompt` 服务，剪贴板写入成功后才增加使用次数；失败则展示错误，不得错误地增加次数或显示「复制成功」。
- **变量模板**：行上显示 `{}` 标识；点击应先进入已有的变量填写流程（推荐调出 `quick` 变量面板），变量未填完整不得把含 `{{变量名}}` 的原文当成最终结果直接复制。
- 明确**不做自动粘贴、自动发送给 AI、模拟键盘、读取其他 App 窗口内容**；用户仍自行切回 AI 输入框按 ⌘V。悬浮窗点击后可能接管焦点，不以要求辅助功能权限来绕过系统限制。
- `always-on-top` 默认开启，可以关闭；切换真实调用原生窗口 API 而非 CSS `z-index`；前端 HTML 演示仅模拟视觉状态。

### FR-17.4 拖动、持久化与关闭

- 只允许拖动标题栏（不含按钮），避免点击列表误触拖动。拖动结束保存窗口逻辑坐标和显示器信息；启动恢复时按当前显示器工作区夹紧，特别处理多屏拔插、Dock/menu bar 与缩放。
- 在 Safari、VS Code、终端/AI 客户端前台下手工验证置顶可见性与复制可用性。macOS 全屏应用/Spaces 上窗口行为受系统规则限制，应记录结果，不对所有 Space 永久悬浮作未经验证的承诺。
- 便签和主窗口共享同一个 SQLite 数据源；编辑、删除、置顶和排序后由 Rust/事件通知便签重新查询，不用两个 `localStorage` 或镜像库。
- 关闭便签不退出程序；关闭主窗时仍有便签则维持运行；通过明确「退出 PromptDock」退出进程。避免出现全窗口隐藏、无法重新打开的死角。

### FR-17.5 本功能验收用例（新增 AT-17～AT-25）

- **AT-17**：Mac 原生安装后，从主窗口显示/收起便签；首次为舒适模式且精确为 420×695 逻辑像素，一次点击切到精简模式 340×270，再一次点击切回。两档均不能任意缩放，重启后恢复最后选择；关闭主窗口后便签仍可独立使用。
- **AT-18**：两档密度都保持恰好 5 个槽位，0/1/4 条时有对应空位；舒适模式可见说明/动作语境，精简模式以标题为主；长标题截断但复制全文完整。
- **AT-19**：第六条置顶被阻止且有清晰提示，原编辑正文不丢；取消旧条后可成功置顶新条。
- **AT-20**：点击便签底部「排序」后，主窗口直接打开既有「管理置顶」；若有其他模态操作则关闭该操作后继续打开。调整顺序并重启后 `pin_order` 保持，复制一次或多次都不改变五条显示顺序。
- **AT-21**：普通条单击，macOS Notes / VS Code 中粘贴与 SQLite 原文逐字符一致，便签不关闭。
- **AT-22**：模板条点击进入变量流程，不能误复制未填写模板；完整变量替换后复制正确。
- **AT-23**：原生置顶开关可切换；拖动位置可记忆，拔除外接显示器后不会留在不可见区域。
- **AT-24**：主窗口删除/编辑/取消置顶时便签实时刷新；多窗口并发不出现重复序号或超过五条。
- **AT-25**：应用完全离线，便签无网络访问、无自动粘贴/发送/辅助功能权限要求。

**与 V1.0 的兼容**：已有 `is_pinned` 在数据库迁移中保留；最多五条已有置顶可赋予稳定 `pin_order`。旧库若超过五条，**不得静默删除提示词**；只给前五条分配便签位置，多出的旧标记进入「待整理的旧置顶」清单，待用户手动取消/替换。新操作遵守五条上限。
